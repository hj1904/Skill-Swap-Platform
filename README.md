**Skill Swap Platform**

Skill Swap is a web-based platform where users can share the skills they know and discover skills they want to learn from other people.
The idea behind the project is simple: instead of learning alone, users can connect with others, exchange knowledge,
and help each other improve their skills.

>> What You Can Do

- Create an account and log in
- Create and manage your profile
- Add and share your skills
- Browse skills shared by other users
- Search for users and skills
- Send and manage skill exchange requests
- Connect with other users for learning
- Manage your profile and account

>>Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

>>Project Structure

The project is mainly divided into:
- `app.py` – handles the main application and routes
- `db.py` – handles database-related operations
- `templates/` – contains the HTML pages
- `static/` – contains CSS, JavaScript and uploaded project files
- `.gitignore` – contains files and folders that should not be uploaded to GitHub

>> Why I Built This

I built Skill Swap as a Python project to create a simple platform for people who want to learn from each other and exchange their knowledge and skills.
It also helped me work with Python, Flask, databases, user authentication, web pages, and connecting the frontend with the backend.

>> Future Improvements
